# Radiant

[English](README.md) | [Čeština](README.cs.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Français](README.fr.md) | [日本語](README.ja.md) | [Polski](README.pl.md) | [Русский](README.ru.md) | [中文](README.zh.md)

**ローカルの音声ファイル**のための、シンプルなネイティブ Android ミュージックプレーヤーです。選んだ1つのフォルダからのみ音楽を再生するため、着信音やボイスメッセージ、その他のサウンドがライブラリに混ざることはありません。

広告なし、アカウント不要、インターネット接続も不要。すべてのデータは端末内に保存されます。

> **対応言語:** 英語、ドイツ語、ロシア語、ウクライナ語、中国語、日本語、フランス語、チェコ語、スペイン語、ポーランド語。**設定 → アプリの言語**で選択するか、*システム*のままにして端末の言語に従わせることができます（端末の言語が未対応の場合は英語が使われます）。

## 機能

- **あなたの音楽、あなたのフォルダ。** フォルダを一度選ぶだけで、Radiant がそのフォルダとサブフォルダをスキャンし、アプリを開くたびに再スキャンします。Android のストレージアクセスフレームワークを使用するため、そのフォルダの外にあるものは一切見えません。
- **ライブラリ:** プレイリスト、アルバム（ファイルのタグから自動でグループ化）、トラック。各セクションで検索と並べ替えができます。
- **プレイリスト:** 作成、名前変更、削除、トラックの追加と削除。*お気に入りのトラック*は常に先頭に固定されます。
- **キュー:** 固定の4つのキューだけを持つ4つ目のセクション（作成・削除はできません）。プレイヤーのボタンまたは「⋮」メニューからトラックを追加でき、削除したり、長押ししてドラッグするか「上へ / 下へ移動」で並べ替えたりできます。
- **ドラッグで並べ替え:** プレイリスト、アルバム、トラックを長押しして並べ替えられます。
- **バックグラウンド再生**（メディア通知、ロック画面での操作、ヘッドセットボタンに対応）。
- **プレイヤー:** 再生/一時停止、次へ/前へ、シーク、シャッフル、リピート（オフ / 全曲 / 1曲）、カバーアート、ファイル形式とビットレートを示す品質バッジ。
- **歌詞:** プレイヤーの「i」の下にあるボタンで歌詞を開きます。Radiant はファイルのタグ（ID3 USLT/SYLT、Vorbis `LYRICS`、M4A `©lyr`）と、トラックの隣にある同名の `.lrc` / `.txt` ファイルから歌詞を探し、アプリを開くたびに再確認します。同期歌詞（`.lrc`）は曲に合わせてスクロールし、現在の行をハイライトして、歌い終えた行をフェードさせます。行をタップするとその位置にジャンプします。通常の歌詞はコンパクトな表示になります。
- **再生速度:** 3倍遅くから3倍速まで0.1刻みで調整でき、音程は維持されます。
- **サウンド設定:** モノラル/ステレオ、音量の正規化、低音・高音ブースト、サブソニックフィルター、10個のプリセット付き12バンドイコライザー。イコライザーは、すべてのトラックに1つのカーブを適用することも、トラックごとに別々のカーブを記憶することもできます。
- **表示言語:** *設定 → アプリの言語*を開くと、上部に*システム*、その下に10言語がアルファベット順に並んだウィンドウが表示されます。変更は再生を中断することなく、すぐに反映されます。
- **テーマ:** ライト、完全な黒のダーク（OLED 画面に最適）、またはシステム設定に従う。Android 12 以降ではダイナミックカラーに対応します。
- **省電力**（設定）: *オフ*、*中*（アニメーションをほぼ無効化、進行状況の更新頻度を低下）、*強*（さらに黒テーマを強制、音量を40%に制限、モノラルのみ、EQ・低音・高音・サブソニック・正規化をバイパス、出力は有線または本体スピーカーのみで Bluetooth 不可、フォルダは手動スキャン、カバーキャッシュを縮小）。
- **トラックの詳細:** タグ、形式、ビットレート、サンプルレート、チャンネル数、ファイルサイズなど。
- **対応形式:** MP3、FLAC、OGG/Opus、M4A/AAC、ALAC、WAV、その他 Android でデコードできるすべての形式。

## 動作環境

- Android 8.0（API 26）以降

## インストール

最新の安定版は、いつでも **[Releases](../../releases/latest)** ページから `.apk` ファイルとして入手できます。

1. 最新リリースの `.apk` をスマートフォンにダウンロードします。
2. 開いて、Android から求められたら提供元不明のアプリのインストールを許可します。
3. Radiant を起動します。

新しいバージョンは、アンインストールせずに古いバージョンの上からインストールできるため、プレイリストや設定は保持されます。

## はじめに

1. アプリを開き、**フォルダを選択**をタップします。
2. 音楽が入っているフォルダを選びます。ライブラリは自動で作成されます。
3. **プレイリスト**、**アルバム**、**トラック**を見て、トラックをタップして再生します。
4. プレイリストを作るには、任意のトラックの横にある **⋮** をタップし、**プレイリストに追加**を選びます。

## ソースからのビルド

JDK 17 と、Android Studio または Gradle 8.9 以降を含む Android SDK が必要です。

- **Android Studio:** プロジェクトを開き、ビルドバリアントを **release** に切り替え（debug ビルドは明らかに遅くなります）、*Build → Build APK(s)* を選びます。
- **コマンドライン:** `gradle assembleRelease` を実行します。
- **GitHub Actions:** リポジトリをフォークし、**Build APK** ワークフローを実行します。APK は実行結果にアーティファクトとして添付されます。

APK は `app/build/outputs/apk/release/app-release.apk` に出力されます。

> **署名について。** 公式リリースは、このリポジトリに含まれていない秘密鍵で署名されています。自分でビルドしたものは標準の Android デバッグキーで署名されるため、問題なくインストールできますが、公式リリースへの上書き更新はできません（どちらかをアンインストールしてからもう一方をインストールしてください）。GitHub Actions で独自に署名したビルドを作りたい場合は、リポジトリのシークレットに `KEYSTORE_BASE64`（base64 エンコードした `.jks` ファイル）と `KEYSTORE_PASSWORD` を追加してください。キーのエイリアスの既定値は `radiant` です。

## サードパーティ製コンポーネント

ALAC（Apple Lossless）の再生には、AndroidX Media3 の FFmpeg デコーダーを使用しています。**Build APK** ワークフローが、未改変の [FFmpeg](https://ffmpeg.org) 6.0 のソースコード（ALAC デコーダーのみ、GPL コンポーネントは無効）と Media3 1.5.1 の拡張機能（Apache-2.0）からこれをビルドし、ネイティブライブラリとしてアプリにリンクします。

FFmpeg は PolyForm Noncommercial ではなく、独自のライセンスである [LGPL 2.1 以降](https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html)のままです。ソースコードは <https://github.com/FFmpeg/FFmpeg>（ブランチ `release/6.0`）で入手できます。ワークフローを変更すれば、独自に改変した FFmpeg でアプリを再ビルドできます。この手順を省いたビルド（たとえば `app/libs` に `.aar` がないローカルビルド）は通常どおり動作しますが、ALAC は再生できません。

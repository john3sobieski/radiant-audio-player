# Radiant

[English](README.md) | [Čeština](README.cs.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Français](README.fr.md) | [日本語](README.ja.md) | [Polski](README.pl.md) | [Русский](README.ru.md) | [中文](README.zh.md)

一款简洁的原生 Android 音乐播放器，专为你的**本地音频文件**而设计。它只播放你所选的那一个文件夹中的音乐，因此手机上的铃声、语音消息和其他声音永远不会出现在你的音乐库中。

无广告、无需账号、无需联网。一切数据都保留在你的设备上。

> **语言：** 英语、德语、俄语、乌克兰语、中文、日语、法语、捷克语、西班牙语和波兰语。可在**设置 → 应用语言**中选择，也可保持为*跟随系统*，以使用手机的语言（如果手机语言不受支持，则使用英语）。

## 功能

- **你的音乐，你的文件夹。** 只需选择一次文件夹；Radiant 会扫描该文件夹及其子文件夹，并在每次打开应用时重新扫描。它使用 Android 的存储访问框架（Storage Access Framework），因此无法看到该文件夹之外的任何内容。
- **音乐库：** 播放列表、专辑（根据文件标签自动分组）和曲目，每个分区都支持搜索和排序。
- **播放列表：** 创建、重命名、删除，添加和移除曲目。*喜欢的曲目*始终固定在顶部。
- **队列：** 第四个分区，固定提供四个队列（不能新建或删除）。可通过播放器中的按钮或“⋮”菜单添加曲目，也可移除曲目，并通过长按拖动或“上移 / 下移”调整顺序。
- **拖动排序：** 长按即可拖动播放列表、专辑和曲目来调整顺序。
- **后台播放**，支持媒体通知、锁屏控制和耳机按键。
- **播放器：** 播放/暂停、下一首/上一首、拖动进度、随机播放、循环（关闭 / 全部 / 单曲）、封面，以及显示文件格式和比特率的音质标识。
- **歌词：** 播放器中“i”按钮下方的按钮可打开歌词。Radiant 会在文件标签（ID3 USLT/SYLT、Vorbis `LYRICS`、M4A `©lyr`）以及曲目旁同名的 `.lrc` / `.txt` 文件中查找歌词，并在每次打开应用时重新检查。同步歌词（`.lrc`）会随歌曲滚动，高亮当前行，并淡化已唱过的行；点按某一行即可跳转到该处。普通歌词以紧凑视图显示。
- **播放速度：** 从慢 3 倍到快 3 倍，步进 0.1，并保持音调不变。
- **音效设置：** 单声道/立体声、音量标准化、低音和高音增强、次声滤波器，以及带 10 个预设的 12 段均衡器。均衡器既可对所有曲目应用同一条曲线，也可为每首曲目分别记住一条曲线。
- **界面语言：** *设置 → 应用语言*会打开一个窗口，顶部固定为*跟随系统*，下面按字母顺序列出十种语言。更改立即生效，不会中断播放。
- **主题：** 浅色、纯黑深色（非常适合 OLED 屏幕）或跟随系统，在 Android 12+ 上支持动态取色。
- **省电模式**（设置）：*关闭*、*中等*（几乎没有动画，进度更新频率降低）或*强力*（另外强制使用黑色主题、音量上限 40%、仅单声道、绕过均衡器/低音/高音/次声/标准化、仅支持有线或手机扬声器输出且不可使用蓝牙、需手动扫描文件夹、封面缓存更小）。
- **曲目详情：** 标签、格式、比特率、采样率、声道、文件大小等。
- **格式：** MP3、FLAC、OGG/Opus、M4A/AAC、ALAC、WAV，以及 Android 能解码的其他任何格式。

## 系统要求

- Android 8.0（API 26）或更高版本

## 安装

最新的稳定版本始终以 `.apk` 文件的形式发布在 **[Releases](../../releases/latest)** 页面。

1. 将最新版本的 `.apk` 下载到手机。
2. 打开它，如果 Android 提示，请允许安装来自未知来源的应用。
3. 启动 Radiant。

新版本可直接覆盖安装，无需卸载旧版本，因此你的播放列表和设置都会保留。

## 快速上手

1. 打开应用，点按**选择文件夹**。
2. 选择存放音乐的文件夹，音乐库会自动填充。
3. 浏览**播放列表**、**专辑**和**曲目**，点按曲目即可播放。
4. 要创建播放列表，请点按任意曲目旁的 **⋮**，然后选择**添加到播放列表**。

## 从源码构建

你需要 JDK 17，以及 Android Studio 或带有 Gradle 8.9+ 的 Android SDK。

- **Android Studio：** 打开项目，将构建变体切换为 **release**（debug 构建明显更慢），然后选择 *Build → Build APK(s)*。
- **命令行：** 运行 `gradle assembleRelease`。
- **GitHub Actions：** Fork 本仓库并运行 **Build APK** 工作流；APK 会作为构建产物附加到该次运行中。

APK 输出到 `app/build/outputs/apk/release/app-release.apk`。

> **签名。** 官方发布版本使用不属于本仓库的私钥签名。你自行构建的版本使用标准的 Android 调试密钥签名，因此可以正常安装，但无法覆盖更新官方发布版本（安装其中一个之前请先卸载另一个）。如果你希望在 GitHub Actions 中生成自己签名的构建，请添加仓库密钥 `KEYSTORE_BASE64`（你的 `.jks` 文件的 base64 编码）和 `KEYSTORE_PASSWORD`；密钥别名默认为 `radiant`。

## 技术栈

Kotlin、Jetpack Compose（Material 3）和 AndroidX Media3（ExoPlayer）。

## 第三方组件

ALAC（Apple Lossless）的播放使用 AndroidX Media3 中的 FFmpeg 解码器。**Build APK** 工作流会基于未经修改的 [FFmpeg](https://ffmpeg.org) 6.0 源代码（仅 ALAC 解码器，未启用任何 GPL 组件）和 Media3 1.5.1 扩展（Apache-2.0）构建它，并将其作为原生库链接到应用中。

FFmpeg 仍适用其自身的许可证 [LGPL 2.1 或更高版本](https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html)，而不是 PolyForm Noncommercial。源代码可在 <https://github.com/FFmpeg/FFmpeg>（分支 `release/6.0`）获取。你可以通过修改工作流，使用自己修改过的 FFmpeg 重新构建应用。未执行此步骤的构建（例如在 `app/libs` 中没有 `.aar` 的本地构建）可正常运行，但无法播放 ALAC。
